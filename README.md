# Avito Tamagotchi

Avito Tamagotchi - игровой сервис, в котором пользователь заботится о виртуальном питомце и развивает его, выполняя действия в приложении. Питомец получает опыт, повышает уровень и участвует в недельном рейтинге, а пользователь поддерживает серию активных дней и получает награды.

## Возможности

- регистрация и вход по email и паролю;
- уход за питомцем: кормление, игры и отдых;
- начисление опыта, повышение уровня и учёт серии активных дней;
- ежедневная статистика действий;
- обновление состояния питомца через WebSocket;
- недельный рейтинг пользователей;
- получение, выбор и активация наград.

## Запуск проекта

### Требования

- Docker и Docker Compose.

### Порядок запуска

1. Клонируйте репозиторий и перейдите в его корневую папку.
2. Создайте файл `.env` как копию `.env.example`.
3. Запустите проект:

```bash
docker compose up --build -d
```

Docker соберёт и запустит фронтенд, бэкенд, PostgreSQL и миграции. После запуска доступны:

- приложение — `http://localhost:3000`;
- API бэкенда — `http://localhost:8080`;
- проверка состояния бэкенда — `http://localhost:8080/healthz`.

Остановить контейнеры:

```bash
docker compose down
```

## Особенности реализации

- При регистрации каждому пользователю автоматически создаётся один питомец.
- Изменение состояния питомца, опыта, уровня, стрика и дневной статистики выполняется в одной транзакции.
- Повторное начисление опыта предотвращается обязательным `Idempotency-Key`.
- Для действий действуют серверные дневные лимиты и периоды восстановления.
- Характеристики питомца ограничены диапазоном от 0 до 100.
- WebSocket подключается по одноразовому билету со сроком жизни 30 секунд.
- Авторизация использует короткоживущий access-токен и обновляемый refresh-токен.
- Недельный рейтинг и награды хранятся в PostgreSQL, миграции применяются автоматически при запуске.

Подробности API и бизнес-логики находятся в каталоге [`backend/docs`](backend/docs).
