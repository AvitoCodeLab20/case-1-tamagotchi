# Награды и недельный лидерборд

## Зачем эта механика нужна сервису

- Награды за уровни связывают рост питомца с полезными действиями
  на Авито.
- Награды за 7- и 14-дневный стрик создают причину
  вернуться завтра.
- Недельный лидерборд даёт короткий соревновательный цикл.
- Выбор приза в лидерборде привлекает как покупателей, так и продавцов.

## Жизненный цикл награды

1. Модуль прогресса подтверждает достижение уровня или стрика, либо завершается
   рейтинговая неделя.
2. Награда выдаётся автоматически и появляется в инвентаре пользователя.
3. Пользователь видит условия, срок действия и, если требуется, выбирает
   категорию или один вариант приза.
4. Пользователь сам применяет награду.
5. Повторное применение того же экземпляра невозможно.

Состояния награды: `issued`, `redeemed`, `expired`, `revoked`.
Рейтинговый приз до выбора имеет отдельное состояние `selection_pending`;
после выбора создаётся обычный экземпляр награды в состоянии `issued`.

По умолчанию обычная награда действует 30 дней с момента выдачи. Выбрать один
из вариантов рейтингового приза нужно в течение 7 дней после завершения недели,
после выбора награда действует 30 дней.

## Награды за уровни

| Уровень | Награда                                                          |
| ---: |------------------------------------------------------------------|
| 5 | Скидка 10% на доставку, максимум 200 рублей                      |
| 10 | Скидка 20% на продвижение одного объявления, максимум 200 рублей |
| 15 | Скидка 15% в выбранной категории, максимум 300 рублей            |
| 20 | Сертификат 300 рублей на продвижение одного объявления           |
| 25 | Выделение цены цветом на 7 дней                                  |
| 30 | Сертификат 500 рублей на продвижение одного объявления           |
| 35 | XL-объявление на 7 дней                                          |
| 40 | XL-объявление и значок на 7 дней                                 |
| 45 | Скидка 20% в выбранной категории, максимум 500 рублей            |
| 50 | Один бесплатный отчёт на Автотеке                                |

После уровня 50 пользователь может начать новый цикл прогрессии.

## Награды за стрик

| Длина непрерывного стрика | Награда |
| ---: | --- |
| 7 дней | Скидка 15% на доставку, максимум 200 рублей |
| 14 дней | Бесплатная доставка, максимум 500 рублей |

Обе награды выдаются в рамках одного непрерывного стрика: получение награды за
14 дней не отменяет уже выданную награду за 7 дней.

## Недельный лидерборд

### Период и источник XP

- Рейтинговая неделя идёт с понедельника 00:00:00 до следующего понедельника
  00:00:00 по московскому времени.
- Учитывается только XP, начисленный в `pet_actions` внутри периода.
  Общий `pets.experience` для недельного рейтинга не используется.
- В рейтинг попадают активные пользователи, заработавшие за неделю больше нуля
  XP. Заблокированные и удалённые аккаунты исключаются.
- Текущая неделя имеет статус `in_progress`: место и возможная награда являются
  предварительными. После закрытия недели результат становится `final`.

Основная сортировка - недельный XP по убыванию. Пользователи с одинаковым XP
получают одинаковое место. Для стабильного порядка отображения внутри ничьей
используются время достижения этого XP и затем `user_id`, но они не меняют
место пользователя.

### Призовые группы

Границы считаются от числа участников после закрытия недели:

- топ 5%: места `1..ceil(participants * 0.05)`;
- топ 10%: следующие места до `ceil(participants * 0.10)`;
- топ 15%: следующие места до `ceil(participants * 0.15)`.

Группы не складываются: участник топ 5% получает один приз топ 5%, а не все три.
Если на границе несколько пользователей с одинаковым XP и одинаковым местом,
вся ничья получает более высокую группу.

| Группа | Один приз на выбор                                                                                         |
| --- |------------------------------------------------------------------------------------------------------------|
| Топ 5% | Сертификат 1000 рублей на продвижение; один отчёт Автотеки; бесплатная доставка до 1000 рублей                   |
| Топ 10% | Сертификат 500 рублей на продвижение; XL-объявление на 7 дней; бесплатная доставка до 500 рублей                     |
| Топ 15% | Сертификат 200 рублей на продвижение; скидка 20% на доставку до 200 рублей; скидка 10% в выбранной категории до 300 рублей |

На странице показываются место пользователя, недельный XP, число участников,
текущая предварительная группа и XP до следующей группы. После финализации
недели выбор приза появляется также в инвентаре наград.

### Финализация недели

Закрытие недели фиксирует границы, число участников, XP и место,
затем создаёт по одному предложению выбора для каждого победителя.

## Безопасность

- `user_id` берётся только из проверенного access-токена. Клиент не передаёт
  владельца награды в теле запроса.
- Каждый экземпляр награды принадлежит одному пользователю. Сервер проверяет
  владельца и статус в той же транзакции, в которой фиксирует применение.
- POST-запросы выбора и применения требуют `Idempotency-Key`. Повтор того же
  запроса возвращает прежний результат, но не создаёт и не применяет бонус
  второй раз.
- Выбор категории проверяется по серверному справочнику допустимых категорий.
  Денежные лимиты и совместимость с объявлением проверяет сервер, а не UI.

## Граница с другими модулями

Модуль наград ожидает следующие подтверждённые входы:

| Вход | Обязательные данные | Владелец источника |
| --- | --- | --- |
| Достигнут уровень | `user_id`, `level`, `progression_cycle`, время | Прогрессия |
| Достигнут стрик | `user_id`, `milestone_days`, `streak_started_on`, время | Стрик/прогрессия |
| Начислен XP | запись `pet_actions` с `user_id`, XP и временем | Действия питомца |
| Пользователь аутентифицирован | `user_id` в request context | Авторизация |

## API

Предлагаемый контракт находится в [`rewards-leaderboard.openapi.yaml`](rewards-leaderboard.openapi.yaml).

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/api/v1/rewards` | Инвентарь наград и ожидающие выбора рейтинговые призы |
| `POST` | `/api/v1/rewards/{reward_id}/redeem` | Применить принадлежащую пользователю награду |
| `GET` | `/api/v1/leaderboard/current` | Текущая неделя, верхушка рейтинга и позиция пользователя |
| `POST` | `/api/v1/leaderboard/awards/{award_id}/select` | Выбрать один вариант рейтингового приза |
